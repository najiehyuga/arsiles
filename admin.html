Pengaturan Database Cloud (Supabase)

Halaman khusus admin untuk mengelola sambungan database Supabase agar pembaruan harga, jadwal, dan biodata les tersimpan permanen di cloud dan otomatis tampil di Vercel.

Status Sinkronisasi Cloud
Terhubung ke Supabase Cloud
Tabel Database

Penyimpanan Gambar

Keamanan Akses
RLS Enabled (Aman)

Kredensial API Supabase

Diambil dari dashboard Supabase Anda (Project Settings → API atau tombol Connect di bagian atas).

Format: https://[id-project].supabase.co (tanpa garis miring / atau /rest/v1 di ujung).

Kunci anon/public aman ditaruh di browser karena hak akses dibatasi oleh kebijakan RLS.

Cadangan & Sinkronisasi

Unduh salinan data les Kak Arsil ke komputer Anda atau muat ulang data paling mutakhir dari Supabase.
